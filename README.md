# QuantumHelix.ai

Landing page for [quantumhelix.ai](https://quantumhelix.ai) — a deep-tech AI company at the intersection of quantum principles, structured intelligence, and scientific rigor.

## Stack

- Static HTML/CSS (no build system)
- Hosted on Cloudflare Workers
- Domain managed via Cloudflare DNS

## Local Development

Open `index.html` in a browser. No dependencies required.

## Deployment

Pushes to `main` are automatically deployed to [quantumhelix.ai](https://quantumhelix.ai) via Cloudflare.
